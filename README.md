## About CoCoCas2Wav.js

https://gigajunky.github.io/coco/

Converts .cas (Cassette) data files to .wav to play into a real Color Computer
Works well depnding on sound hardware..  Seems to work well on most PCs audio out with sound on very high without distortion..
If it don't work on one, try anouther.  Does not seem to work on my Samsung Phones/Tablets.. Maybe sound is not loud enough?
Currently no options or validation to keep it as simple as posible..  only supports 9600 bit rate.
Not sure other rates would help for other audio hardware?

## Getting Started

### Prerequisites

* A Color Computer 
* A Audio Cable to connect between Computers
* some Color Computer  program files (.cas or .dsk)

or

* A Timex/Sinclair ZX81
* A Audio Cable to connect between Computers
* some ZX81 program files (.p)

### Installation

works from browser but can work localy by copying source files.

<!-- USAGE EXAMPLES -->
## Usage

* Make sure computers are ready from the Prerequisites above.
* Select a file(s) from browser web page.
* click on the file of more then one.
* Enter command to load file on (CoCo: CLOAD for Bas or CLOADM for bin)
* Press the play button.
* When done you will et an OK. Type EXEC to run.

You may need to adjust the volume and not all devices are compatible.
